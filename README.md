# Weather App

A Python command-line app that shows the current weather and temperature (°F and °C) for any city, using the OpenWeatherMap API. :)

## Run it

1. `pip install requests python-dotenv`
2. Create a `.env` file with `API_KEY=your_openweathermap_key`
3. `python app.py`

## Built with

Python, requests, python-dotenv, OpenWeatherMap API
